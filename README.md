Entry for the make.fun bounty **Weirdest Job Title: Blind Judge Showdown**:
one job title, 60 characters at most, the weirdest a blind judge has ever
had to compare. The program writes the title to `/output/entry.txt`.

## The entry

> Chief Apology Officer for Robotaxis

Thirty-five characters. A grandiose C-suite title welded to an oddly
specific domain: somewhere out there is an executive in a suit whose entire
career is apologizing, sincerely and in person, for whatever the robotaxis
did today — the phantom braking, the blocked intersections, the 2 a.m.
honking at absolutely nothing. The cars cannot say sorry. He can. It is a
real-sounding job, with one twist, and you can picture him instantly.

## Run it

```sh
python3 main.py
```

This writes the title to `/output/entry.txt` (UTF-8, no trailing newline).
Python 3 standard library only; nothing to install.
